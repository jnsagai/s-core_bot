# Evaluation cases

Case files here are **development measurements** until an expert review is recorded in the file's
`review_status` (master spec §13.2; release-grade evaluation is F008). Gold evidence locations are
chosen by reading the pinned sources directly, never from this system's own search output.

- `retrieval-dev.yaml` — initial retrieval cases (F004), agent-authored, unreviewed. Format:
  `specs/004-hybrid-search/contracts/eval-cases.md`.

# S-CORE Docs Assistant 1.0.0rc1 — local release candidate (2026-09-30)

A local-first documentation assistant for Eclipse S-CORE (independent community project, not
endorsed by Eclipse or S-CORE). It runs entirely on your machine: no API keys, paid services,
telemetry or cloud fallback.

## What is in it
- **Sources and snapshots:** approved S-CORE sources synced to exact revisions, normalized, and
  built into immutable, validated snapshots with a local embedding index. Activation, rollback,
  export and import are atomic (F001–F003).
- **Search:** exact requirement IDs, keyword and semantic search, answered from one pinned
  snapshot (F004).
- **Answers:** validated, cited answers from the local model. The system repairs a failed answer
  once, otherwise falls back to quoting excerpts. It never invents citations, marks text that
  addresses AI assistants, and does not log questions (F005).
- **Web UI:** ask, search, compare, evidence dialog, export; memory-only conversations; strict CSP;
  accessible, and verified in a real browser and with a screen reader (F006).
- **Comparison:** explicit two-snapshot comparison with typed differences. It never claims deletion
  and never infers a release label (F007, sped up in amendment A).
- **Quality:** a 100-case suite with a frozen held-out split, human review import, adversarial and
  offline checks, performance budgets and a release report (F008).
- **Portable use:** a hardened container image, a Compose profile (app on 127.0.0.1 only, private
  runtime without a host port), offline package, fresh install and restore, SBOM, runbooks (F009).

## Evidence
Release report: `docs/quality/release-report-local-v1.0-2026-09-29.md`. **42 gates pass, 1 is open,
and the public profile is deferred.**
- Held-out ×3: recall@10 96.2%, safe handling 14/14, false abstention 0/26, citation integrity
  40/40.
- Exact-ID lookup 2168/2168.
- Adversarial 0/10 failures.
- Blocked-egress operation passes.
- Performance: answer p95 7.6 s warm; comparison p50 13.1 s.
- Containers: app on loopback only; restore keeps citations (50/50 chunks, 23/23 citations);
  native and container behave the same on all 10 API endpoints.
- 1126 backend tests passed; frontend tests passed; traceability complete.

**Open before 1.0.0:** a person's review of the 60 development cases (`reviewed_suite`).

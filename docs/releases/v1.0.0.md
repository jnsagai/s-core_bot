# S-CORE Docs Assistant 1.0.0 — local release (2026-09-30)

A local-first documentation assistant for Eclipse S-CORE (independent community project, not
endorsed by Eclipse or S-CORE). It runs entirely on your machine: no API keys, paid services,
telemetry or cloud fallback.

Contents are unchanged from [1.0.0rc1](v1.0.0-rc1.md) apart from the version. The last open gate,
the review of the 60 development cases, was closed by the owner's blanket acceptance (A-056).

gates pass**. The public profile is deferred and not required for the local release.
